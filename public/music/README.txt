# Romantic Music Folder

Place an optional background song here:
- our-song.mp3

Tips:
- If `our-song.mp3` is not present, the app gracefully falls back to a gentle synthesized ambient chime or peaceful silent mode with clear toggle.
- Background audio never autoplays; the user controls it via the floating music button.
- You can change the music path in `src/data/personalization.ts`.
