# Chat Screenshots Folder

Place your chat screenshots here:
- chat-01.jpg
- chat-02.jpg
- chat-03.jpg
- chat-04.jpg
- chat-05.jpg

Tips:
- Screenshots can be any aspect ratio (portrait phone screenshots work best).
- You can add more screenshots (e.g. chat-06.jpg, chat-07.jpg) by adding them to `src/data/personalization.ts`.
- If an image file has not been added yet, the app displays a cute romantic placeholder.
